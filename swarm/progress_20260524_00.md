## Diagnostic finding

The Nemotron `FAIL_INFRA_M11B_NEMOTRON` is **substantive**, not merely
bookkeeping.

The M11b runner only calls `apply_quantization(...)` through `score_regime(...)`.
The `m11b_top1`, `m11b_top5`, `m11b_top10`, and `static_top10` regimes use that
path. The `static_1pct` baseline does not: if no reusable score cache is
provided, the runner calls `score_targets(...)` directly for `static_1pct`
without applying W4A16 quantization/protection.

Granite avoided this bug because its M11b packet reused `static_1pct` from the
earlier M2 packet, where `static_1pct` had actual quantization metadata. The
Nemotron run did not reuse a score run directory, so `static_1pct` was scored
without quantization.
